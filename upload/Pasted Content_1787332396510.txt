Do not create giant duplicated functions.

# 93. SECURITY

Do not:

* expose API keys
* send local data unexpectedly
* introduce unnecessary analytics
* store secrets in localStorage
* use unsafe HTML injection
* trust imported data blindly

Sanitize user-generated content where required.
